# 买量工坊 UA Studio

Blender 休闲游戏买量广告一键式制作工具箱。从建场景到出成片，全部「选中 → 点一个按钮」。

> 目标版本：Blender 4.5+（在本机 Blender 5.1.2 上开发与全量测试通过）
> 当前版本：**0.2.1**（72 项自动化验收断言）

## 关于

本项目由 **AI 全程编写**——基于 GLM 大模型驱动的编程 Agent，从需求分析、架构设计、逐模块实现、物理调参到自动化测试全部由 AI 完成，人类负责提需求、验收效果和决策方向。

- AI 模型：GLM（智谱）
- Agent 框架：ZCode CLI
- 人类角色：产品经理 + 测试验收

## 安装

**方式一（推荐）**：双击 `install.command`（macOS），自动构建并安装到 Blender。

**方式二**：Blender → 编辑 → 偏好设置 → 插件 → 右上角箭头 → 从磁盘安装，选择 `dist/ua_studio-*.zip`（无 zip 时先运行 `blender --command extension build --source-dir . --output-dir dist`）。

安装后：3D 视口按 `N` 打开右侧栏 → 找到 **「买量工坊」** 面板。

## 渲染质量与画面风格（⑦ 渲染页）

- **四档质量预设**：草稿（EEVEE 16 采样预览）→ 标准（64+光追）→ 高质（256+光追+运动模糊）→ 电影（Cycles 256+降噪）
- **色彩风格**：明快/浓郁/清冷/暖调（曝光+伽马组合）
- **景深聚焦**：选中物体一键对焦，f 值滑杆
- **运动模糊**：快速运动元素的拖影质感
- **氛围微尘**：大面积慢速漂浮粒子层（⑤ 物理页），画面空间质感
- **材质质感**：糖果轻次表面、果冻重次表面、宝石清漆镀层
- ⚠ 实验性：合成链辉光/晕影（5.1.2 构建的合成器节点组求值有崩溃风险，默认关闭，出错可关闭 Blender 重开并保持关闭状态）

一键生成完整可编辑工程（含分镜结构、4 个卡点标记、结尾卡场景），生成后自动切到主场景。

## 前置插件说明

- **内置启用**：Node Wrangler、FBX/glTF 导入器
- **自动联网安装**（首次使用对应功能时自动装，也可在面板手动装）：
  - Cell Fracture（破碎）、Extra Mesh Objects、LoopTools、Scatter Objects（来自 extensions.blender.org）
  - BlenderKit（免费素材库）、Animation Nodes（可选，来自 GitHub Release）
- 一键安装需要开启 Blender 的「在线访问」（首次会引导，面板里有一键开启按钮）

## 已知注意事项

- EEVEE 引擎 ID、Action 槽位化 F 曲线、粒子属性名等 5.x API 差异已在 `core/util.py` / `anim_lib.py` 内做适配
- 渲染走 CLI 子进程（先存副本再 `blender -b` 渲染），规避同会话新建对象的依赖图时序问题
- 流体预设低分辨率起步（默认 48），烘焙耗时与分辨率立方相关
- 「限时挑战」等默认文案均为占位，面板内可改
